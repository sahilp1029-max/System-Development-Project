# Safari Kid Attendance & Billing System
**Systems Analysis & Design | Professional Portfolio Project**

## Project Overview
Developed a custom, full-stack digital solution for **Safari Kid** to replace a manual, paper-based check-in and billing process. This system was designed to eliminate administrative bottlenecks, improve student data security, and automate weekly financial reporting.

## Tech Stack
* **Backend:** Python 3.10+ (Logic and Calculation Engine)
* **Database:** SQL / SQLite (Relational Data Management)
* **Frontend:** HTML5, CSS3 (Responsive UI/UX)
* **Environment:** VS Code, Git/GitHub

## Systems Analysis & Design (SDLC)
This project followed a rigorous **System Development Life Cycle** methodology, featuring:
* **Project Scheduling:** Developed **PERT** and **Gantt Charts** to manage a 7-week delivery timeline, identifying a critical path to ensure completion by May 5th.
* **Dialogue Design:** Created a **Dialogue Sequence Diagram** to optimize user navigation and minimize data entry errors during high-traffic check-in periods.
* **Risk Mitigation:** Designed a comprehensive maintenance plan covering preventive, perfective, adaptive, and corrective actions to ensure 99.9% system uptime.

## Key Features
* **Automated Billing Logic:** Python-based calculations that map real-time attendance data directly to weekly revenue reports.
* **Secure Check-In/Out:** Hashed ID verification for parents to ensure maximum student safety and data integrity.
* **Admin Dashboard:** A centralized interface for staff to manage student profiles, monitor attendance, and generate billing statements.

## Repository Structure
* `app.py` / `web_app.py`: Main application controllers and routing logic.
* `safari_kid.db`: SQL database containing relational tables for students and attendance.
* `templates/`: UI components including the Dashboard, Billing, and Login screens.
* `admin_billing.html`: Specialized view for administrative revenue management.
